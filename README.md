# MoneyPlan

Apple Pay の支払いを自動で記録する、自分用の家計簿アプリです（SwiftUI、iOS 17 以降）。
ショートカットの「取引」オートメーションから、アプリを開かずに裏で記録します。銀行の入出金は通知文の貼り付けか CSV で取り込めます。ホーム画面・ロック画面のウィジェット付き。

## できること

| タブ | 内容 |
|---|---|
| ホーム | 今月使ったお金、予算の残り、今日から1日に使える額、前月の同じ日までとの比較、累計のペース（このままだと月末いくら）、直近7日、費目の上位、最近の記録 |
| 明細 | 月ごとの一覧（日付ごと）、支出・収入・収支、検索、費目で絞り込み、スワイプで削除・「今日もう一度」、削除の取り消し |
| 分析 | 費目のドーナツと一覧（タップで中身）、日ごとの支出と平均、費目ごとの予算、よく使うお店、支払い方法、6か月の推移 |
| 設定 | 予算・月の始まり（給料日始まりも可）、費目ごとの予算、Apple Pay の設定手順、通知文から記録、CSV 読み込み、覚えた分類、ウィジェット連携、CSV 書き出し、バックアップ |

- 入力はテンキー。店名を入れると費目が自動で決まり、自分で直した費目はお店ごとに覚えます（過去の記録もまとめて直ります）
- CSV は銀行・カード会社の明細（UTF-8 / Shift_JIS）を読み込み、Apple Pay で記録済みのもの（同じ日・同じ金額）は飛ばせます

### ショートカットのアクション

| アクション | 内容 |
|---|---|
| 支払いを記録 | 金額・店名・カードを渡すと記録（アプリは開かない）。「¥1,234」のような文字でも読み取る |
| 通知文から記録 | 入出金通知のメールや SMS の文章から、日付・金額・入金か出金か・相手を読み取って記録 |
| 今月の支出を取得 | 今月の支出（数値）と、予算の残りを返す |
| 支出を手入力 | アプリを開いて入力画面を出す |

### Apple Pay を自動で記録する設定

1. ショートカットアプリ →「オートメーション」→ ＋ →「取引」
2. 記録したいカードを選び、「すぐに実行」→ 次へ
3. 「新規の空のオートメーション」→ アクションに「MoneyPlan › 支払いを記録」
4. 金額 ←「ショートカットの入力 › 金額」、店名 ←「加盟店」、カード ←「カードまたはパス」

アプリの「設定 › Apple Pay を自動で記録」にも同じ手順があります。

### ウィジェット

| ウィジェット | サイズ |
|---|---|
| 今月の支出 | 小・中（＋ボタン付き）・ロック画面（長方形・円・1行） |
| 最近の記録 | 中・大（＋ボタン付き） |
| 費目の内訳 | 小・中・大 |

署名に App Group が入っていればそれで共有します。入っていない場合（普段の署名ツール）は、Shift Note と同じように**カレンダーの 2001年1月2日に集計メモを1件だけ**保存してウィジェットに渡します。初回は「設定 › ウィジェット › カレンダーへのアクセスを許可」をタップしてください。

## IPA の作り方（Mac 不要）

`main` に push すると、GitHub Actions（`.github/workflows/ios.yml`）が自動でビルドします。手動で動かすときは **Actions** タブ →「iOS Build」→「Run workflow」。

1. 完了した実行を開き、下の **Artifacts** から `MoneyPlan-unsigned-番号.ipa` をダウンロード
2. 普段使っている署名ツールで署名してインストール

ビルドの途中で、金額・通知文・CSV の読み取りと集計のテストも行います。見本データでの各画面のスクリーンショットは `ci-screenshots` ブランチに置かれます。

## 構成

```
Shared/            データ・読み取り・集計・ウィジェットの表示（アプリとウィジェットで共通）
MoneyPlan/         アプリ本体（SwiftUI）とショートカットのアクション（App Intents）
MoneyPlanWidget/   ウィジェット（WidgetKit）
MoneyPlanTests/    ユニットテスト
tools/icon.py      アプリアイコンの生成
project.yml        XcodeGen の設定
```

データは端末の中（App Group が使えるときはその中）の `ledger.json` に保存し、外部には送りません。
